Administrator Roles

There are two levels of administrator access.

Administrator

Can manage website content, including news, gallery images and achievements.

Super Administrator

Has full administrative privileges, including managing other administrator accounts.

Important Security Notice

Only authorized super administrators should create or assign administrator accounts. Keep login credentials confidential.
